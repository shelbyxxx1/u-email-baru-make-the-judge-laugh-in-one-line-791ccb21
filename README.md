A deterministic, single-line gym-membership joke for the make.fun bounty. The entry uses only the Python standard library, with no network access or external input files.

## Run

```sh
python3 main.py
```

The program writes `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` when it is set and non-empty, otherwise to `/output/entry.txt`. It creates parent directories as needed and writes exactly the following line plus one trailing newline:

> I joined a gym in January, went twice, and now I pay $40 a month for a stranger to email me that he misses me, like an ex with better cardio.
